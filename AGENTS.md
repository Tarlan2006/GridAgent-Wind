# AGENTS.md — hack-d830a856-nexcel-solution (HackAlem AI, трек «Энергетика»)

## Кейс (Самрук-Казына)
Agentic AI, прогнозирующий почасовую выработку 2 ветротурбин на горизонте 24-48ч.
Система сама получает архивные прогнозы погоды по координатам турбин (см. `data/turbines.json`),
запускает модель прогноза и выдаёт почасовой результат. Тестовый период: 1-28 февраля 2026,
walk-forward (на каждую дату — только архивные прогнозы погоды, доступные на тот момент, не факт задним числом).
История для обучения: 11.03.2023 - 31.01.2026, 10-минутные замеры (`Статистическое время`,
`Средняя скорость ветра(m/s)`, `Нормализованная активная мощность`, `Средняя температура окружающей среды(°C)`).

## Архитектура (dual-core)
- `src/core/` — детерминированное ядро: power curve, feature engineering, сама модель прогноза. Без LLM.
- `src/weather/` — клиент архивных прогнозов погоды по координатам (+ mock-клиент для офлайн-демо).
- `src/agents/` — LLM-оркестратор и его tool-schemas (`orchestrator.py`, `tools.py`). LLM только вызывает
  инструменты и объясняет результат, сам числа не считает и не придумывает (см. `docs/skills/skill-agentic-loop.md`).
- `src/app.py` — FastAPI (`/api/forecast`, `/api/update`, `/api/chat`, `/api/status`) + HTML-консоль `src/web/index.html`.
- `src/backtest.py` — walk-forward прогон по тестовому периоду Feb 2026, это и есть метрика оценки.
